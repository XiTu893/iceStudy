# 小初高 全量知识图谱及数字孪生

一款面向中小学学生与家长的学习辅导桌面软件。覆盖**数学、英语、物理、语文**全学段知识点，内置**知识图谱浏览**、**数字孪生**与**自适应诊断**等核心功能，离线运行、即装即用，无需联网。

---

## 软件能做什么

### 一、按"目录"翻书式地浏览全部知识点

软件参照**书籍目录**的方式组织知识，从学段到年级再到册、章、节，层层展开，一目了然：

- **第一层 · 学段**：小学 → 初中 → 高中
- **第二层 · 年级**：如一年级、七年级、高一……
- **第三层 · 册与章**：对应各版本教材的单元章节
- **第四层 · 知识点**：每一个具体的学习条目

点击任意知识点，即可在中部看到它的**知识图谱**——哪些是它的先修基础（在左）、哪些依赖它展开（在右），以及它与其他知识点的关系；右侧详情面板列出该知识点的描述、掌握标准、所属册章等。

### 二、数字孪生：可操作、可动画、可检验的知识点模型

针对重点与抽象知识点，提供**可交互的数字孪生**：拖动参数、观察图形/数值联动，配合分步讲解、动画与随堂检验，把"看公式"变成"动手试"。

当前共内置 **846 个数字孪生**，覆盖数学全部 846 个知识点（覆盖率 **100%**），其中 **65 个 3D 必需点**全部使用 Three.js 真 3D 场景呈现：

- **v1 精心设计的交互孪生（25 个）**：支持拖动参数、动画与实时计算，覆盖 11 类可视化模板；
- **v2 知识孪生（821 个）**：基于 Three.js 的轻量化 3D 场景，按知识点类别（数与代数、图形与几何、统计与概率、综合与实践）提供专属图形、数轴、柱图或流程块，并配有分步讲解与随堂检验。

v1 的 11 类交互模板如下：

| 模板 | 交互方式 | 对应孪生 |
| --- | --- | --- |
| `fraction-bar` 分数条 | 等分、涂色、合并 | 分数的意义、异分母分数加减 |
| `dissection` 剪拼割补 | 剪拼/等分重排，面积联动 | 勾股定理、平行四边形的面积、三角形的面积、圆的面积 |
| `function-curve` 函数图象 | 拖动参数，图象与交点联动 | 一次函数、二次函数 y=a(x−h)²+k |
| `balance` 天平/方程 | 加减砝码，等式两边同步 | 方程的意义、等式的性质、移项与合并同类项解方程 |
| `number-line` 数轴 | 拖动取点，正负与距离 | 认识负数、数轴 |
| `dynamic-geometry` 动态几何 | 拖动顶点，角度实时计算 | 三角形内角和、圆周角定理 |
| `transform` 图形变换 | 拖动对称轴/平移向量/旋转角 | 轴对称、平移、旋转、轴对称图形 |
| `data-chart` 统计图 | 拖动柱顶调数据，平均数联动 | 条形统计图、平均数 |
| `probability` 概率 | 抽样/频率实验 | 概率的意义、用频率估计概率 |
| `array-area` 点阵面积 | 拖动行列数，显示"几个几" | 乘法的意义 |
| `shape-net` 展开图 | 展开/折叠，找相对面 | 长方体纸盒的展开图 |

**可以从哪里进入数字孪生：**

1. **顶部导航「数字孪生」** → 打开孪生目录，卡片上点击 **「打开孪生」**；
2. **「知识图谱」** 中选中带孪生的知识点 → 右侧详情内先看**孪生预览**，再点 **「打开数字孪生」**；
3. **首页「数字孪生」入口** → **「进入数字孪生 →」**；
4. **老师端「课程体系」→「知识点」** → 展开行内查看知识关系小图与**孪生预览**，可直接播放。

每个孪生都包含：分步讲解、可交互视图、随堂检验（选择题/填空）、教学提示。

### 三、自适应诊断，找到薄弱根因

选择要诊断的知识点（或整册、整章），软件会沿"先修关系"自动出题：

- 答对 → 继续深入；答错 → 回溯到更基础的先修点
- 最终给出**薄弱根因**与**学习路径**，告诉你该从哪里补起
- 支持数值填空、选择题等题型，答完即反馈

### 四、学习档案，记录每个孩子的成长

- 可为多个孩子建立档案，各自独立保存诊断记录
- 随时回看某位孩子的掌握情况、薄弱根因、学习路径
- 诊断结果可**生成分享图**，方便家长保存或分享

### 五、老师端：课程体系与孪生覆盖

- 按学段/年级/册章查看课程体系全貌
- 查看各知识点的**孪生覆盖**，快速定位可演示的可视化内容
- 「知识点」标签下可展开单个知识点，行内查看知识关系与孪生预览

### 六、课程体系 / 知识图谱 / 数字孪生的联动

三者以**知识点 ID**（如 `cnm_p173`）为统一主键，通过「当前知识点上下文」双向联动：

- **课程体系「知识点」**：展开任一知识点，行内同时显示先修/后继小图与孪生首帧预览，可一键播放、查看图谱或诊断；
- **知识图谱**：选中知识点后，详情面板显示课程位置面包屑与孪生预览，可跳到课程体系对应位置；
- **数字孪生**：页面顶部显示学科 / 年级 / 大类 / 册章面包屑，可回跳知识图谱、课程位置或诊断；
- **进度回流**：孪生的分步学习与检验结果写入本地进度，课程体系显示「已体验 / 已完成」，学习档案聚合展示孪生进度；
- **深链**：`#/curriculum?topic=cnm_xxx&tab=topics`、`#/explore?subject=math&topic=cnm_xxx`、`#/twins/cnm_xxx`。

### 七、快速搜索与关联浏览

- **全局搜索**：按 `Ctrl + K`（macOS `Cmd + K`）打开，跨全部学科的**知识点、数字孪生、册章/大类**统一检索，结果分组展示，方向键 + Enter 快速定位，点击直接深链到对应视图；
- **分段返回路径**：进入更细层级（知识点详情、孪生播放、诊断过程）后，顶部显示可点击的路径，每段都可返回对应层级，不再只能靠浏览器后退；
- **统一关联面板**：任一知识点都展示**先修、后继、同章知识点**与孪生状态，并在图谱详情、课程体系展开行、孪生播放页三处保持一致；
- **筛选状态可分享**：年级、大类、搜索词等筛选写入 URL，链接可分享、可后退，路径也能恢复到精确的浏览层级；
- **浏览入口**：首页提供全局搜索引导与学段/年级快捷下钻，孪生目录支持按学科与年级筛选，846 个孪生全部可检索；
- **孪生弹层播放**：在课程体系与知识图谱中点击「播放完整孪生」会弹出可关闭的播放器，支持 **关闭 / 返回 / 全屏 / 独立页打开**，无需离开当前知识点上下文；
- **启动体验**：全局搜索索引改为首次唤起时才加载，启动期间显示明确的载入进度页，减少首屏等待感；
- **自动 / 手动播放**：数字孪生支持一键**自动播放**（可暂停、调速 0.5×/1×/2×、点击步骤进度跳转），也支持**手动**逐步演示与上一步/下一步；`animate` 动作按设定时长平滑插值，仅含高亮的步骤在自动播放时会逐个点亮，避免静态场景生硬跳变；
- **真 3D 状态驱动**：3D 渲染器支持 `$stateKey` 属性绑定并采用增量更新（不重建 WebGL 场景），状态变化直接驱动对象的位置、缩放、旋转与颜色；批量生成的孪生统一内置随步骤移动的动态标记，自动播放时可见连续运动。

## 运行说明

- **绿色免安装**：直接运行 `release/iceStudy.exe`（仓库随附的最新构建），无需安装、不写注册表。
- **自行构建**：安装版可通过 `npm run tauri build` 生成 NSIS / MSI 安装包。
- **离线使用**：全部知识库与孪生配置内置于程序，断网也能用。
- **适用系统**：Windows 10 / 11。

> 提示：若看不到「数字孪生」入口，说明运行的是旧版本程序，请使用最新构建的 exe / 安装包。

## 开发与构建

技术栈：**React 19 + Vite + TypeScript**，桌面端使用 **Tauri 2**。

```bash
npm install          # 安装依赖
npm run dev          # 本地开发（Vite）
npm run test         # 运行测试（vitest）
npm run build        # 前端构建（含数据打包）
npm run tauri build  # 打包桌面端 exe / MSI / NSIS 安装包
```

**数据管线（data.bin）**

知识库与孪生配置在构建时统一打包为 `public/data.bin`，运行优先从该文件加载，缺失或损坏时自动降级到 `public/data/*.json`：

```bash
npm run copy:data    # 同步数据到 public/data
npm run pack:data    # 打包 public/data.bin（含 SHA-256 校验）
```

`npm run build` 已自动串联 `copy:data → pack:data → tsc → vite build`。

**构建产物**

- 前端：`dist/`（含 `dist/data.bin`）
- 绿色版 exe：`src-tauri/target/release/icestudy-tauri.exe`
- MSI：`src-tauri/target/release/bundle/msi/iceStudy_0.1.0_x64_en-US.msi`
- NSIS：`src-tauri/target/release/bundle/nsis/iceStudy_0.1.0_x64-setup.exe`

**孪生扩展**

- 模板：`src/twin/templates/`（v1 交互模板）、`src/twin/scene3d/`（v2 真 3D 渲染器）
- 孪生配置：`src/twin/specs/v2/math/`（v2，按知识点 ID 命名）；在 `scripts/twin/validate.ts`（构建期校验）、`scripts/twin/smoke.ts`（冒烟）与 `src/twin/runtime/registry.ts`（运行时加载）登记
- 新增孪生需满足：schemaVersion 为 2、含 camera 与 objects 的 3D 场景、≥1 个步骤与检验、`answer ∈ options`、校验零错误
- 覆盖率检查：`npm run twin:coverage` 可查看知识点覆盖与 3D 必需点缺口（当前 846/846，缺口 0）
