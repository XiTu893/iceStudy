# 小初高·全量知识图谱

一款面向中小学学生与家长的学习辅导桌面软件。覆盖**数学、英语、物理、语文**全学段知识点，内置**知识图谱浏览**与**自适应诊断**两大核心功能，离线运行、即装即用，无需联网。

---

## 软件能做什么

### 一、按"目录"翻书式地浏览全部知识点

软件参照**书籍目录**的方式组织知识，从学段到年级再到册、章、节，层层展开，一目了然：

- **第一层 · 学段**：小学 → 初中 → 高中
- **第二层 · 年级**：如一年级、七年级、高一……
- **第三层 · 册与章**：对应各版本教材的单元章节
- **第四层 · 知识点**：每一个具体的学习条目

点击任意知识点，即可在中部看到它的**知识图谱**——哪些是它的先修基础（在左）、哪些依赖它展开（在右），以及它与其他知识点的关系；右侧详情面板列出该知识点的描述、掌握标准、所属册章等。

### 二、自适应诊断，找到薄弱根因

选择要诊断的知识点（或整册、整章），软件会沿"先修关系"自动出题：

- 答对 → 继续深入；答错 → 回溯到更基础的先修点
- 最终给出**薄弱根因**与**学习路径**，告诉你该从哪里补起
- 支持数值填空、选择题等题型，答完即反馈

### 三、学习档案，记录每个孩子的成长

- 可为多个孩子建立档案，各自独立保存诊断记录
- 随时回看某位孩子的掌握情况、薄弱根因、学习路径
- 诊断结果可**生成分享图**，方便家长保存或分享

## 运行说明

- **绿色免安装**：解压后双击 `iceStudy.exe` 即可运行，无需安装、不写注册表。
- **离线使用**：全部知识库内置于程序，断网也能用。
- **适用系统**：Windows 10 / 11。
